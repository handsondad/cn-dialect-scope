# 写问答

问题放在 `src/data/questions/<主题>.ts`，类型见同目录的 `types.ts`。新问题加进对应主题的数组就会出现在网站上，主题列表按 `difficulty` 排。

| 主题 | 文件 | 讲什么 |
|---|---|---|
| `why` 🧭 为什么说话不一样 | `why.ts` | 方言怎么来的、普通话怎么来的、方言会不会消失 |
| `family` 🌳 方言大家族 | `family.ts` | 分区、官话、方言跟着人走到海外 |
| `sound` 🎵 声调的秘密 | `sound.ts` | 声调、粤语九声、入声和古诗 |
| `words` 💬 一个意思各地说 | `words.ts` | 同一个意思各地的词，背后的古汉语 |
| `fun` 🎲 好玩的方言 | `fun.ts` | 最有味道的词，一个字的意思怎么跑 |

## 字段

- `id`：英文短横线，全站唯一，也是配音的文件夹名。改了 id 要重新配音。
- `title`：小念口吻的问句，带「？」。
- `trigger`：小念刚刚遇到的事，一句话，具体到人和地方（"过年去上海外婆家……"）。
- `difficulty`：1 入门、2 进阶、3 挑战。每个主题第一个问题是 1。
- `words`：这一问讲到的方言词，1～10 个，每个都要在标题或问答里出现。页面上列成小卡片。
- `concepts`：知识库里相关概念的 slug（`data/concepts/*.json`），页面上能点进方言地图看各地说法。
- `dialogue`：5～8 轮，每轮 `nian`、`dad`，可选 `show`。
- `show`：爸爸这一段旁边配的东西：
  - `{ kind: "steps", frames: [{ icon, label }, …] }`：图解步骤，2 步以上；
  - `{ kind: "say", lines: [{ text, label, voice?, sub? }, …] }`：「听一听」，1～9 句，每句 ≤16 字。`label` 是哪里话，`sub` 是拼音或普通话意思，`voice` 是 `yue` / `dongbei` / `putonghua`；
  - `image`、`video`：图片、视频，放在 `public/` 里，要写 `alt`。
- `parentTip`：给大人：背景、学界的不同说法、出处。这里可以用术语。

## 检查器会拦的

`node tests/dialogue-rules.mjs <文件>`：

- 标题要是问句；5～8 轮；`words` 1～10 个、都出现过、不重复。
- 除了最后一轮，小念每句都带「？」；最后一轮以「我懂了」或「我明白了」开头。
- **从第二轮起，小念要接住爸爸上一句里的一个两字词**（比如爸爸说"官话"，小念问"官话是当官的人说的话吗？"）。虚词和"方言、爸爸、地方、大家"这类每段都有的词不算。
- 爸爸每句 20～170 个字。
- 不用术语：音位、调值、调类、声母、韵母、韵尾、音系、中古音、上古音、构拟、反切、本字、俗字、训读、变调、同源词、语族、语支、方言岛、底层。换成大白话："开头的音""收尾的口形""古时候的读法""老字"。

## 写好的标准（检查器管不到的）

- **一轮只讲一件事**。爸爸一句话里最多一个新名词。
- **数字要有来头**：七大方言、十个大区、九声六调、四个声调、一千二百年前，都要能在 `parentTip` 或 `facts.md` 里找到依据。说不准就说"一大半""很多"。
- **例句用真的**：优先用 `data/` 里的例句（"你搁这儿嘎哈呢？""冇问题。""侬好。"），它们在地图页和游戏里也会出现，孩子会觉得眼熟。
- **拼音只在需要时出现**：讲声调、讲读音变化才写拼音或粤拼（mā、mou5），其余时候写汉字。
- **方言字要解释**：冇、咗、侬、呒没 第一次出现时，爸爸马上说出普通话意思。
- **结尾能动手**：问外婆一句话、去方言地图上点一个词、用手指画声调、给表姐出题。

## 例子（`why.ts` 的 `why-different`，节选）

```ts
{
  nian: "爸爸，外婆刚才说的「侬饭吃过了伐」是什么意思？我怎么一句也听不懂？",
  dad: "外婆在问你「你吃过饭了吗」。「侬」就是你，「伐」就是吗。她说的是上海话，是一种方言。……"
},
{
  nian: "为什么各地都有自己的方言？大家不都是中国人吗？",
  dad: "我们玩过传话游戏吧？一句话从第一个人传到第十个人，每人改一点点，最后就变了样。……",
  show: { kind: "steps", frames: [{ icon: "🗣️", label: "一句话" }, { icon: "👂", label: "每人改一点" }, { icon: "⛰️", label: "山河隔开" }, { icon: "🌳", label: "变成方言" }] }
},
{
  nian: "传话游戏传到最后会全变吗？上海话和普通话还有一样的地方吗？",
  dad: "不会全变，它们本来是一家人。外婆说的「饭」「吃」，写出来的字和普通话一样，只是读音变了。……"
}
```

第二轮小念接住了"各地都有自己的方言"，第三轮接住了"传话游戏"，一路往深里问。
